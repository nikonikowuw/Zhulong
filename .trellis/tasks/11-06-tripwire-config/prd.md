# 绊线配置与算法读取

用户已确认一起打通配置与算法读取。每个任务算法可配置最多 8 条带稳定 ID、名称、有序端点、A→B/B→A/双向的绊线。支持绘制、调整端点、删除、撤销、切换算法保留、保存重载。坐标是原始全幅归一化坐标。旧 ROI/MASK/CROP 行为兼容；无绊线旧数据正常读取。

验收：前后端拒绝非法/重复 ID、非有限越界坐标、短线与非法方向；任务配置保存后经算法隔离的 IPC 到达 SDK；晚连接/重连可重放所有算法的最新配置；SDK 提供只读区域 JSON 与变更修订号、当前帧实际裁剪窗口及坐标转换。旧算法参数原文不变。覆盖清空与多算法隔离。

不包括越线判断、跟踪器、计数、告警和独立方向箭头。
