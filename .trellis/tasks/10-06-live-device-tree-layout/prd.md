# 实时预览 UI 升级：左侧媒体设备树与右侧分屏工作区 (PRD)

## Goal

将 Zhulong 实时监控模块 (`features/live`) 从单一宫格与模态弹窗选流模式，彻底重构升级为安防监控系统 (VMS/NVR) 业界标准的「左侧媒体设备树面板 + 右侧多分屏监控工作区」双栏联动交互架构。提升多路监控巡查时的通道发现效率、流分发效率与多视口操作直观度。

---

## Requirements

### REQ-1: 左侧媒体设备树面板 (`LiveDeviceTree`)
- **REQ-1.1 树级层次与状态感知**：
  - 一级节点为摄像机设备：展示摄像机名称、在线/离线/错误健康状态指示圆点、展开/折叠箭头指示。
  - 二级节点为摄像机流通道（Main Stream 主码流 / Sub Stream 子码流）：展示码流角色徽章、分辨率/帧率简要标识、推流/运行状态。
- **REQ-1.2 实时模糊搜索与过滤**：
  - 树顶部提供搜索框，支持按摄像机名称、ID 关键字快速即时过滤，匹配项自动展开树节点。
- **REQ-1.3 播放状态关联指示**：
  - 实时比对右侧分屏已分配的流槽位。若某通道正在右侧某视口播放，该通道节点右侧显示高亮状态标识（如 `视口 1` 徽标），防止重复多路点播或辅助快速定位。
- **REQ-1.4 点播与通道装载交互**：
  - 双击或点击流节点右侧的「播放」按钮，自动将该流通道装载到当前「选中的视口 (Active Slot)」。
  - 若当前未选中视口，自动分配给首个空闲视口；若所有视口均占满，则默认替换当前选中的视口或视口 0。
- **REQ-1.5 面板折叠与空间伸缩**：
  - 支持一键折叠（Collapse）左侧树面板，收起后释放宽度给右侧监控分屏，折叠状态保持在 `localStorage` 中。
  - 在移动端/小屏幕下以浮动遮罩抽屉（Drawer）形式展现，点击遮罩或外部自动关闭。

### REQ-2: 右侧分屏监控工作区升级 (`LiveDashboard` & `LiveViewport`)
- **REQ-2.1 视口选中聚焦状态 (Active Slot Focus)**：
  - 引入 `selectedSlotIndex` 状态。用户点击任意视口，该视口呈现高亮激活光环（如蓝色外发光边框与序号徽章高亮）。
  - 支持键盘导航或快捷选中，配合左侧设备树实现流畅的「选视口 -> 点设备流」连贯操作。
- **REQ-2.2 顶部视口控制栏与快速全局操作**：
  - 保留 1x1、2x2、3x3 宫格快速切换（带键盘 `1` / `4` / `9` 快捷键）。
  - 顶部增加当前激活视口状态提示（例如：“当前聚焦：视口 2 (无信号) / (大门球机·主流)”）。
  - 提供全局快捷操作：如「一键清空所有视口 (Clear All)」。
- **REQ-2.3 视口内部精简与联动优化**：
  - 视口保留原有的独立悬浮工具栏（快照截图、Telemetry 显隐、主/子流快速切换、单视口全屏、移除视口）。
  - 空视口占位引导升级：明确提示「点击选中此视口，并在左侧设备树双击流通道快速接入」，保留直接打开弹窗的手动分配选项。

### REQ-3: 国际化与工程质量门禁
- **REQ-3.1 完整多语言支持**：
  - 新增所有交互文案、设备树节点名称、搜索占位符、操作按钮均同步补充 `en`、`zh-Hans`、`zh-Hant`。
- **REQ-3.2 严格质量门禁**：
  - TypeScript 严格类型检查无 `any`。
  - ESLint 规范 0 错误 0 警告。
  - Vitest 单元/交互测试 100% 通过（新增设备树、布局联动测试）。
  - Vite 生产构建 `npm run build` 成功。
