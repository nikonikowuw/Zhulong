# 感知记录多维批量与多选导出

## Goal

在 Zhulong 边缘智能运维宿主中实现感知记录（人脸识别、安全告警、目标抓拍、机动车抓拍）多维批量导出与列表主动多选导出能力。
秉持「边缘宿主高能效、客户端算力深度卸载」架构原则：
1. **算力卸载**：由前端浏览器离屏 Canvas 负责目标检测框与研判标签的绘制，零消耗边缘嵌入式板卡（RK3568/RK3588）的 CPU、GPU/RGA 与编码通道，保护实时流分析流水线零抖动；
2. **灵活组合**：支持按当前筛选条件一键批量导出，支持跨 Tab 维度自由组合（人脸识别、安全告警、目标抓拍、机动车抓拍），也支持在列表（表格/卡片）中任意勾选多条记录进行定向导出；
3. **交付介质与控存流**：支持纯结构化报表（CSV，全量不设限）及图片证据包（ZIP）；客户端采用受控并发与即插即收的内存流水线，彻底防止浏览器单 Tab 内存膨胀或崩溃。

## 业务需求 (Requirements)

### R1. 列表主动多选交互 (Selective Export)
- **表格视图 (Table View)**：
  - 在 Recognitions、Alarms、Captures 以及 Vehicles 列表中引入首列复选框（Checkbox）；
  - 表头复选框支持当前页“全选 / 反选 / 半选 (indeterminate)”；
  - 每一行支持单选勾选，并提供行选中高亮样式；
- **卡片视图 (Grid View)**：
  - 卡片左上角提供悬浮/常驻复选框，点击勾选不触发卡片详情弹窗；
- **多选联动浮动操作条 (Bulk Action Bar)**：
  - 当选中记录数 $N > 0$ 时，页面底部（或工具栏）浮现多选操作栏，显示 `已选中 N 项`；
  - 提供「导出选中项」与「清空选择」按钮；
  - 点击「导出选中项」后唤起导出弹窗，导出数据范围默认锁定为已勾选的 $N$ 条记录；
- **Tab 隔离与生命周期原则**：
  - 各 Tab 对应不同的数据实体与字段模型，多选状态严格在当前 Tab 内部生效；
  - 切换 Tab 时主动清空选中项并收起浮动操作条，杜绝跨 Tab 实体混杂。

### R2. 全局条件批量导出与多维 Tab 自由组合 (Query Batch Export)
- 在感知记录页顶部工具栏常驻「批量导出」按钮（与刷新、时间范围选择器同列）；
- 点击打开「感知记录导出」对话框：
  - **Tab 维度自由组合**：
    - `[x] 人脸识别记录 (recognitions)`
    - `[x] 安全告警记录 (alarms)`
    - `[x] 目标抓拍记录 (captures)`
    - `[x] 机动车抓拍记录 (vehicles，即 targetType=vehicle 抓拍)`
    - 初始状态默认勾选当前正在浏览的 Tab，支持用户自由多选或一键全选；
  - **继承当前筛选上下文与时间快照锁定**：
    - 自动继承顶部工具栏已生效的时间范围（如“今日全天”或自定义绝对时间段）、摄像机筛选、以及相关细项过滤；
    - **时间快照防漂移**：触发全量批量拉取时，前端自动将时间范围锁定（`endTime` 固化为触发当下的绝对 RFC3339 时间戳），生成稳定的时间窗口快照，规避边缘设备持续写入导致翻页偏移（LIMIT/OFFSET 滑动产生重复记录）；
    - 弹窗内直观展示当前条件匹配到的预估记录条数。

### R3. 导出内容选型与交互配置 (Export Options)
- **结构化报表（CSV 格式）**：
  - 勾选后，选中的每个维度独立生成一份 `.csv` 文件；
  - 采用 UTF-8 with BOM 编码（解决 Windows Excel 打开中文乱码问题）；
  - 包含时间、摄像机名称、算法包名称与版本、目标/人员标识、相似度/置信度得分、PTS 帧时间戳、证据图片路径等关键字段；
- **图片证据文件（ZIP 归档）**：
  - 开关：`[ ] 导出抓拍图片证据`；
  - 导出图片类型：支持选择全景大图 (`imagePath`) 与特写抠图 (`cropPath` / `faceImagePath`)；
  - **检测框与标签离屏烧录开关（核心）**：
    - `[x] 在图片上绘制目标检测框与研判标签`；
    - 开启后，由前端离屏 Canvas 将检测框（`box` / `bodyBox`）及研判信息（如人员姓名、告警类型、车型车牌、相似度得分）合成烧录进图片后打包；
    - 关闭时，直接导出原图文件；
- **容量与耗时预警**：
  - 纯 CSV 导出完全不设上限，支持全量秒级下载；
  - 包含图片导出时，若检测到匹配记录较多（> 200 张），弹窗给出预估体积和耗时提示，并提供可选的条数限制输入框（默认导出全部，亦可指定前 N 条）。

### R4. 客户端算力卸载与 Canvas 离屏渲染 (Client-side Compute Offloading)
- **零服务端图像处理**：
  - 边缘宿主坚决不引入 OpenCV、Cairo 或额外图像处理 CGO/Go 库；
  - 边缘宿主仅通过现有 `/api/v1/media/content/*` 提供静态图片字节流；
- **Canvas 离屏绘制管线**：
  - **安全网络加载**：通过带凭据的 `fetch(getMediaUrl(path), { credentials: 'same-origin' })` 将图片拉取为 Blob，再通过 `createImageBitmap` / Object URL 送入 Canvas，兼顾 HTTP 状态码校验、Cookie 鉴权与请求中断（AbortController），彻底杜绝跨域污染（Tainted Canvas）；
  - 使用 `OffscreenCanvas`（降级回退到隐式 `HTMLCanvasElement`）；
  - 提取记录中的归一化坐标 `box`（`[x1, y1, x2, y2]`）并乘以图片实际宽高尺寸换算为绝对物理像素；
  - 绘制半透明抗锯齿检测框（使用项目设计系统规范色盘，包含 emerald、amber、sky、rose 等）；
  - 绘制半透明标签胶囊底块与文字（对齐详情弹窗视觉标准）；**具备顶边碰撞翻转机制**：当目标框贴近图像顶部时，标签自动翻转绘制于框内上沿，杜绝文字被画布边缘截断；
  - 识别记录若存在人脸与人体的 `bodyBox`，按同构逻辑区分双框绘制；
  - 输出为 JPEG 格式 Blob (`image/jpeg`, 质量 0.85)，绘图后显式清空画布释放显存。

### R5. 内存安全与流式打包流水线 (Streamlined ZIP & Memory Control)
- **流水线即收即放**：
  - 使用受控并发池（Worker 并发数 3~4）抓取图片与绘制；
  - 采用流式打包策略：处理一张图片即压入 ZIP 目录树，随后立即释放原始 `Image` 对象、Canvas 像素缓冲区和临时 Blob，切断引用以触发垃圾回收；
  - 确保即使连续导出数百至上千张带框图片，浏览器标签页的 JS 堆内存与 GPU 纹理占用始终稳定在安全阈值（< 50MB），彻底避免页面崩溃或卡死；
- **直观进度与取消机制**：
  - 弹窗展示实时阶段与数值进度条（如 `正在离屏渲染带框图片: 35 / 120...`）；
  - 提供「取消导出」按钮，随时安全中断导出流水线并释放资源。

### R6. 国际化与视觉一致性
- 完整补充 `zh-Hans.json`、`zh-Hant.json`、`en.json` 的多语言文案（含多选操作条、导出弹窗各配置项、进度提示、错误提示）；
- 严格遵循现有的 shadcn/ui 组件规范与 Tailwind CSS 样式，深色/浅色模式完美适配。

## 验收标准 (Acceptance Criteria)

- [ ] **AC-1 (多选体验闭环)**：
  - Recognitions、Alarms、Captures 以及 Vehicles 在表格视图与卡片视图下均能顺畅多选；
  - 选中项计数实时准确，操作条动画自然；一键清空与“导出选中项”逻辑准确。
- [ ] **AC-2 (多 Tab 组合与过滤继承)**：
  - 批量导出弹窗能自由勾选 1~4 个 Tab 维度；
  - 弹窗正确继承当前已选择的时间窗口（包括“今日全天”及自定义时段）与摄像机过滤条件。
- [ ] **AC-3 (CSV 报表完整性与兼容性)**：
  - 导出的 CSV 文件带有 UTF-8 BOM 头，在 Windows Excel 中打开中文字符绝无乱码；
  - 各字段（时间、摄像机名、算法名、标识、置信度等）映射准确无遗漏。
- [ ] **AC-4 (客户端离屏检测框烧录保真度)**：
  - 勾选“绘制目标检测框”时，导出的图片精确画出检测框与标签；
  - 框选坐标在不同分辨率原图下均无偏移或变形，文字清晰易读，颜色与系统视觉规范一致；
  - 未勾选时导出原图文件。
- [ ] **AC-5 (内存与性能稳定性)**：
  - 导出带图压缩包（包含数十至数百张图片）期间，浏览器页面帧率保持流畅，无“页面无响应”弹窗；
  - 进度指示器实时步进，完成后自动弹出 ZIP 文件保存下载。
- [ ] **AC-6 (边缘宿主零额外负载)**：
  - 导出全流程中，边缘宿主除正常响应静态资源与数据查询外，无额外图像重采样、编码或压缩开销，CPU 波动维持在极低水平。
- [ ] **AC-7 (代码质量与门禁)**：
  - 新增核心逻辑具备充分的前端单元测试（Vitest 浏览器无头环境），覆盖多选状态管理、CSV 转换、离屏 Canvas 绘制和流式流水线；
  - `make check`（前端 lint、类型检查、测试）完全通过。

## 范围外 (Non-Goals)
- 服务端（Go 侧）使用 CGO/OpenCV 或 Cairo 进行图片重绘制（坚守纯前端算力卸载，保护边缘设备）。
- 录像回放流切片导出（录像导出属于独立的 mediafile/recording 体系）。
