# 摄像机配置管理与状态大盘前端 (PRD)

## 1. 目标与定位 (Goal)

在 Web 前端构建现代、优雅且高可靠的摄像机配置管理与实时状态大盘（`features/camera`），完整对接后端 `/api/v1/cameras` 业务接口与 `/api/v1/cameras/events` SSE 实时事件通道：
1. **多视图与设备大盘**：直观展示摄像机列表、启用状态、主/子流规格（分辨率、编码格式、帧率）以及多维正交健康状态（Online / Offline / Error / Unknown，Degraded / Stale 标识）。
2. **凭据安全与工程调试便利**：支持摄像机 RTSP 地址与凭据的安全查看、明文显隐（👁️ 图标）与一键复制功能，极大简化工程调试（如 VLC / ffplay 测试）。
3. **闭环配置管理**：提供新增、编辑与删除弹窗表单。在提交保存时呈现 3～5 秒原子探测门禁的 Loading 反馈与细粒度失败原因（如认证失败、超时、不支持的格式）；编辑时利用 CAS Revision 乐观锁避免并发覆写。
4. **一键快速诊断**：提供手动即时探测诊断工具（Diagnose），呈现网络连通性、SDP 解析详情与实时丢包/时延指标。
5. **SSE 实时状态流转**：前端接入 SSE `/api/v1/cameras/events`，通过初始 Snapshot 建立基线，随后的流状态变更（Session: Starting/Running/Idle/Error、Health: Online/Offline）秒级增量响应，杜绝无效 HTTP 轮询。
6. **视觉与国际化**：统一延续 Apple 极简科技美学（暗黑/浅色模式、半透明毛玻璃、精细微交互），完整支持 `en`、`zh-Hans`、`zh-Hant` 三语无缝切换。

## 2. 需求规范 (Requirements)

### 2.1 导航与顶栏集成 (Navigation)
- **R1.1 模块导航**：在顶栏或工作区主栏增加一级导航切换：「系统概览 (Overview)」与「摄像机 (Cameras)」（预留未来「实时预览 (Live)」入口）。
- **R1.2 认证守卫隔离**：摄像机管理视图严格受 `AuthGuard` 保护，仅在登录状态下渲染与请求数据。
- **R1.3 视图状态同步**：支持 URL hash（例如 `#/cameras`、`#/overview`）或路由状态切换，刷新页面保持在当前视图。

### 2.2 摄像机列表与健康状态呈现 (Camera List & Dashboard)
- **R2.1 统计概览指标**：列表顶部提供聚合状态指标卡（全部摄像机数、在线数、离线数、异常/降级数）。
- **R2.2 摄像机卡片/列表项**：
  - 设备基本信息：摄像机名称、ID、更新时间。
  - 启用开关切换：提供快捷开关（Toggle Switch），一键启用/禁用，调用更新接口并即时反馈。
  - 健康状态徽标（Health Status Badge）：
    - `online`：绿灯常亮。
    - `offline`：灰灯。
    - `error`：红灯，Tooltip 显示错误原因。
    - `unknown`：黄色或柔和脉冲。
    - `degraded`（子流异常）：橙色警示标。
    - `stale`（探活超期）：灰白过期警告标。
  - 会话流状态（Session State）：`running`（推流中）、`idle`（待机空闲）、`starting`（拉流中）、`error`。
  - 媒体流参数：主流与子流的分辨率（如 `1920x1080`）、编码格式（`H.264` / `H.265`）、帧率（`25 fps`）、传输协议（`TCP` / `UDP`）。
- **R2.3 空状态与加载状态**：优雅的 Skeleton 加载骨架屏与空列表引导添加提示。

### 2.3 凭据查看与一键复制 (Credentials Utility)
- **R3.1 明文显隐控制**：默认对 RTSP URL 中的密码部分进行掩码显示（`****`），点击眼睛图标（👁️）可切换为完整明文展示。
- **R3.2 一键复制可用地址**：提供一键复制完整 RTSP URL（含用户名密码）到剪贴板功能，并在按钮旁边展示临时成功提示（如 "已复制!" 提示浮层）。

### 2.4 新增与编辑摄像机 (Create & Edit Flow)
- **R4.1 表单字段**：
  - 摄像机名称（1～64 字符，必填）。
  - 主流 RTSP URL（必填，格式合法性校验）。
  - 主流传输协议（默认 TCP，支持切换 UDP）。
  - 子流 RTSP URL（可选）。
  - 子流传输协议（可选，默认 TCP）。
  - 启用状态（默认开启）。
- **R4.2 原子探测门禁交互**：
  - 提交表单时，按钮进入探测 Loading 态，并显示提示文案（如「正在连接摄像机并探测视频流参数 (3-5s)...」）。
  - 探测成功即完成入库，自动刷新列表并弹出成功通知。
  - 探测失败（后端 422/400 拦截）时，表单保持打开，精准回显错误原因（如认证凭据错误、网络超时、缺少视频轨道等）。
- **R4.3 编辑与 CAS Revision 保护**：
  - 编辑表单预填当前名称、流地址与传输模式。
  - 提交时携带摄像机的当前 `revision`。若遭遇并发修改（HTTP 409），弹出冲突提示并引导用户重新获取最新数据。

### 2.5 主动诊断与删除确认 (Diagnose & Delete)
- **R5.1 一键主动诊断**：操作栏提供「诊断」按钮，调用 `POST /api/v1/cameras/:id/diagnose`，弹窗展示诊断详情：
  - 探测总耗时（毫秒）；
  - 主流与子流 SDP 解析状态；
  - 探测到的关键帧与音视频轨道信息。
- **R5.2 删除二次确认**：点击删除弹出模态确认对话框，告知将级联注销媒体流与关联配置，防止误触。

### 2.6 SSE 实时状态流转 (Real-Time State Sync)
- **R6.1 EventSource 长连接管理**：在用户登录后自动连接 `/api/v1/cameras/events`。
- **R6.2 快照与增量更新**：
  - 处理 `event: snapshot`：全量初始化摄像机状态字典。
  - 处理 `event: update`：就地更新对应摄像机的健康与会话状态，UI 无感平滑过渡。
- **R6.3 健壮重连与断网降级**：连接中断时采用指数退避自动重连，连接恢复后自动重新拉取最新快照。

### 2.7 国际化与响应式设计 (i18n & UX)
- **R7.1 多语言覆盖**：所有新增文本均提供 `en`、`zh-Hans`、`zh-Hant` 键值。
- **R7.2 移动端与桌面端自适应**：在宽屏展示卡片网格与详细数据，在窄屏自适应折叠为紧凑卡片，支持流畅触控。

## 3. 验收标准 (Acceptance Criteria)

- [x] **AC-1 (导航与视图拆分)**：已登录用户可在顶栏无缝切换「系统概览 (Overview)」与「摄像机管理 (Cameras)」，URL/视图状态保持同步，未登录用户无法访问。
- [x] **AC-2 (摄像机列表与状态展示)**：完整渲染摄像机列表，包含设备名称、启用开关、正交健康状态（online/offline/error/unknown）与降级/过期标识（degraded/stale），主流与子流分辨率、编码格式与帧率。
- [x] **AC-3 (新增与编辑流程)**：表单提供主流 URL（必填）与子流 URL（可选）、传输模式（TCP/UDP）、名称校验；提交时呈现 3~5s 异步探测 Loading；探测失败时友好回显业务错误码与详细说明；编辑时携带 revision CAS 并优雅处理 409 冲突。
- [x] **AC-4 (凭据安全显隐与一键复制)**：提供 RTSP URL 与密码明文显隐切换（👁️ 图标）；提供一键复制完整带凭据 RTSP 地址功能并提供即时复制成功反馈。
- [x] **AC-5 (一键诊断与删除确认)**：支持对单台摄像机发起即时主动探测诊断（Diagnose），弹出诊断报告（网络时延、SDP 解析、编码参数）；删除时提供二次确认并友好提示级联影响。
- [x] **AC-6 (SSE 实时状态同步)**：挂载 `useCameraEvents` 监听 SSE 事件流，接收 `snapshot` 初始化状态，接收 `update` 实时更新单机健康与会话状态，无需轮询；断线自动重连。
- [x] **AC-7 (多语言与门禁质量)**：所有界面文案、状态标签、表单提示与错误信息完整覆盖 `en` / `zh-Hans` / `zh-Hant`；全量通过 `npm run type-check`、`npm run lint`、`npm test` 与 `make check`。
