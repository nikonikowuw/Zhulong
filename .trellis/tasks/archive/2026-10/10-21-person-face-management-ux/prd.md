# PRD: 人员与人脸管理交互与 UI 现代化升级 (方案 B)

## 1. 目标与价值 (Goal & Value)

将当前以老派 CRUD 表格和割裂弹窗为中心的人员/人脸管理，升级为以**视觉底库为中心**的高体验现代管理系统（方案 B）：
1. **闭环录入流程**：新建人员时允许直接拖拽/上传首张底库照片，创建完成即自动提取特征建模并设为主图，彻底终结“建完人再去表格找行录脸”的割裂折返跑。
2. **现代化人员详情抽屉 (PersonsDetailSheet)**：把原先局促的二级弹窗重构为右侧滑出的现代化抽屉（Sheet），提供一人多照大图画廊、多文件批量上传队列、常驻且优雅的操作栏、清晰的主图指示。
3. **表格 (Table) ⇄ 卡片画廊 (Grid) 双视图自由切换**：支持大卡片视图快速直观浏览人脸底库与建模状态，与经典数据密集表格无缝切换。
4. **三语国际化与深浅主题严格遵循规范**：遵循 OKLCH 语义颜色、Radix / Tailwind v4、无 any、浏览器无头测试 100% 通过。

## 2. 功能需求清单 (Requirements)

### 2.1 新建人员一体化录入 (Integrated Creation)
- 新建弹窗（`PersonsActionDialog`）支持可选的首张人脸照片选择/拖拽区域。
- 选择照片后实时展示圆形或微缩卡片预览与移除按钮。
- 提交时：先调用创建人员接口，若携带了照片，则紧接着调用添加人脸接口，并联动更新首张人脸为主图，统一给出友好 toast 提示。若人脸提取失败，给予明确提示但不阻断人员创建。

### 2.2 人员详情与人脸管理抽屉 (PersonsDetailSheet)
- 点击人员行的“人脸底库”、表格行、画廊卡片时，从右侧滑出抽屉（Sheet）。
- **头部**：展示人员姓名、工号 Badge、录入时间，提供编辑与删除入口。
- **人脸画廊与批量上传**：
  - 支持多文件批量多选上传（`<input multiple>` 及拖拽上传）。
  - 卡片网格：不再暴力裁剪，合理比例展示人脸，带有圆角与微阴影。
  - 主图角标（Badge）清晰可见（绿色/蓝绿色语义 Token）。
  - 操作按钮（设为主图、删除、放大预览）常驻或半常驻在卡片底部，触屏友好，杜绝反人类的纯 Hover 蒙层。
  - 删除人脸带有确认或即时撤销/Toast 反馈。
  - 保留并满足已有的测试契约（如 `data-testid="face-card"`、主图指示文本等）。

### 2.3 双视图切换 (Table View ⇄ Grid View)
- 在人员管理页面的主操作区或工具栏提供视图切换开关（List / Grid 图标按钮）。
- **网格卡片视图 (Grid View)**：
  - 响应式网格展示（`grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4`）。
  - 醒目的人脸大封面/头像、人员姓名、工号、底库照片数量状态（如“3 张底库”或“未录入人脸”）。
  - 支持行/卡片选中复选框，与批量删除操作栏联动。
  - 点击卡片直接滑出详情抽屉。
- 保留并兼容已有的 URL 分页与搜索状态（`useTableUrlState`）。

## 3. 验收标准 (Acceptance Criteria)

- [x] **AC-1**: 新建人员弹窗支持直接选择照片并一体化上传，若不选照片仍可正常建纯信息档案。
- [x] **AC-2**: 点击人脸底库/卡片弹出右侧抽屉（Sheet），支持多选图片批量上传与设为主图。
- [x] **AC-3**: 支持 Table 视图与 Grid 视图切换，两种视图下均能正常搜索、分页、多选批量删除。
- [x] **AC-4**: 补充完整的英/简/繁三语国际化字段（`en.json`, `zh-Hans.json`, `zh-Hant.json`），无硬编码文本。
- [x] **AC-5**: 前端所有单元测试/组件测试（Vitest 浏览器无头环境）及 `pnpm lint` 100% 通过。
