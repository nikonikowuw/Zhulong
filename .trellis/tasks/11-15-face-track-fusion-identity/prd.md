# 人脸识别轨迹级跨帧融合与身份投票

## Goal

在不降低单帧比对阈值的前提下，提升 CCTV 场景（走近、转头、模糊帧）的识别召回与身份稳定性。
改动只在 `packages/face_recognition`（onnx / rk3568 双档位同步），不改 ABI / IPC / Go / 前端。

## Confirmed Facts（现状问题）

- 跨帧关联只靠特征：当前帧须与融合向量 **和** 最高质量锚点余弦均 `>= 0.62`。困难帧（侧脸/模糊/小脸）
  帧间同人相似度常低于 0.62，轨迹断开、状态从头攒，最需要融合的帧融不进去。
- 融合是对所有帧做质量加权累加（软上限 6.0），大量中低质帧稀释少数好帧。
- 身份逐帧独立判定，`matched` 在侧脸帧上 1/0 抖动；没有轨迹级证据累积。
- spec 约束：`track_id` 归宿主独占，包内跟踪 ID **不得**经 IPC 出口（`record-guidelines.md` §1）。

## Requirements

1. **空间优先 + 特征否决的关联**：观测携带归一化人脸框；与状态上一帧框空间一致（IoU / 中心距 + 尺度比）时，
   只要求特征余弦 `>= fusion_spatial_similarity_threshold`（默认 0.40）作为防串人否决；空间不一致或无框时
   回落原「纯特征」门槛 `fusion_similarity_threshold`（默认 0.62）。同帧仍一对一贪心互斥，空间一致边优先。
2. **Top-K 高质量帧融合**：每状态只保留质量最高的 `K=5` 帧单位特征，融合 = 质量加权和再 L2 归一化；
   锚点 = 库内最高质量帧（保持原「历史最高质量锚点」语义）。
3. **轨迹级身份决策**（`enable_track_identity`，默认开，仅在融合开启且观测有状态时生效）：
   - 本帧融合特征严格命中（阈值 + 分差）→ 确认；
   - 或最近 5 帧中 ≥ `track_vote_min_hits`（默认 2）帧的**单帧特征** top-1 为同一身份，
     且分数 `>= threshold - track_vote_relax`（默认 0.05）、分差门禁通过，本帧也满足 → 确认；
   - 确认后锁定，侧脸帧继承身份；连续 2 帧严格命中另一身份才切换。
   - 输出 `similarity` 取轨迹内该身份的最高分；`candidates` 保持本帧证据语义不变。
4. 新参数走 `.env` / 进程级 / 任务级 JSON 三层优先级与越界回落，**不进** `config.schema.json`（专家参数）。
5. 包内跟踪键只在包内使用，不写入 `track_id`。

## Acceptance Criteria

- [x] 无框观测（旧调用形态）行为与原纯特征融合一致，既有融合单测全部通过。
- [x] 空间一致 + 特征 0.45 的同人帧能融合；空间一致但特征 < 0.40 的异人被否决；空间不一致回落 0.62。
- [x] Top-K：低质帧不进入满库；融合输出恒为单位向量；锚点为最高质量帧。
- [x] 身份：严格命中立即确认；2/5 近阈值投票确认；单帧近阈值不确认；分差不过不计票；确认后锁定、
      单帧冲突不切换、连续 2 帧冲突切换；关闭开关回到逐帧决策。
- [x] 参数解析：默认值、边界、越界回落、env 覆盖均有单测。
- [x] `make -C packages/face_recognition/onnx unit-test`、`make pkg-drift-check` 通过；rk3568 只编译（本机无板端 SDK 前缀，未交叉编译，仅做源码同步 + 漂移门禁）。

## Out Of Scope

- 阈值/最小脸尺寸默认值调整（需现场标定数据）、模型替换、ROI/二次检测、YUV 色彩契约、宿主输出时机变更。
